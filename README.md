# CampusConnect AI

> **Your Next Opportunity Starts Here.** CampusConnect AI is an interactive platform that matches college students with internships, hackathons, workshops, and student communities tailored to their skills, interests, and career goals.

---

## 🚀 Overview

CampusConnect AI eliminates the need for students to scour multiple group chats, messaging channels, and bulletin boards. By utilizing smart matching heuristics, it matches student profiles with highly relevant professional and educational opportunities.

This repository contains the front-end interface, interactive dashboard prototype, and matches simulation engine.

---

## ✨ Features

- **AI-Powered Matching Engine:** Instantly evaluates student profiles (skills, interests, location) and suggests personalized opportunities.
- **Interactive Dashboard:** View, filter, and track applications/registrations for hackathons, internships, and workshops in real-time.
- **Dynamic Opportunities Feed:** Up-to-date listings with comprehensive details, tags, and application links.
- **Modern, Sleek UI/UX:** Built with a clean, dark-themed, glassmorphic layout, micro-interactions, responsive navigation, and custom illustrations.

---

## 🛠️ Tech Stack

- **Structure:** HTML5 (Semantic elements, responsive layout)
- **Styling:** Custom CSS3 (Vibrant color palette, CSS variables, flexbox/grid layout, media queries, animations)
- **Logic:** Vanilla JavaScript (Dynamic matches filtering, interactive modal simulations, tab navigation, profile updates)

## 📦 Getting Started

To run this project locally, simply clone the repository and open the `index.html` file in your browser:

### 1. Clone the Repository
```bash
git clone https://github.com/RohanCodes118/CampusConnect-AI.git
cd CampusConnect-AI
```

### 2. Run the Application
Open `index.html` directly in your preferred web browser, or use a local development server like Live Server in VS Code:
```bash
# Using python to spin up a quick local server
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your browser.
